DND Registration (TRAI)

Register on Do Not Disturb (DND)

Official TRAI mechanism to stop telemarketing calls in India

  1. SMS START 0 to 1909 to activate full DND (blocks all categories)
  2. Or register at ndnc.in — TRAI's National Do Not Call portal
  3. Download the TRAI DND app (Android/iOS) to report violations directly
  4. After registration, file complaints for any spam received — violators face ₹2,500/call penalty

Setup Guides for Every Phone

Step-by-step instructions to enable spam call blocking on your device.

📱

Android (Google Phone)

Built-in spam protection on Pixel & stock Android

  1. Open Phone app → tap ⋮ → Settings
  2. Tap Caller ID & spam
  3. Enable "See caller and spam ID"
  4. Enable "Filter spam calls" — sends suspected spam to voicemail
  5. For manual blocking: open recent calls → long-press number → Block
🍎

iPhone (iOS)

Silence Unknown Callers + manual blocking

  1. Go to Settings → Phone
  2. Enable "Silence Unknown Callers" — sends unknown numbers to voicemail
  3. For manual blocking: open Recents → tap ⓘ next to number → Block this Caller
  4. View blocked list at Settings → Phone → Blocked Contacts
  5. Install Truecaller for caller ID: Settings → Phone → Call Blocking → enable Truecaller
🔒

Samsung Galaxy

Samsung's built-in Smart Call + Hiya integration

  1. Open Phone app → ⋮ → Settings → Caller ID
  2. Enable Smart Call (powered by Hiya) for caller identification
  3. Enable "Block spam and scam calls"
  4. Set blocking level: Block all suspected spam for maximum protection
  5. Go to Settings → Block numbers → enable "Block unknown callers"
📞

Truecaller (All Phones)

Best third-party spam blocker for India

  1. Install Truecaller from Play Store / App Store
  2. Set as default caller ID app when prompted
  3. Enable "Block top spammers" in Truecaller settings
  4. Turn on "Block hidden numbers" and "Block foreign numbers"
  5. Use Community Block List — auto-blocks numbers reported by 10+ users
🇮🇳

TRAI DND App

Official government app to file complaints

  1. Download TRAI DND from Play Store / App Store
  2. Register with your mobile number
  3. Set DND preference → select "Fully Blocked" for all categories
  4. Report spam: tap "Register Complaint" → select the spam call from log
  5. TRAI penalizes violators ₹2,500 per call — complaints work!
🌐

Carrier-Level Blocking

Block spam at the network level

  1. Jio: MyJio app → DND → activate Do Not Disturb
  2. Airtel: Airtel Thanks app → More → DND Activation
  3. Vi: SMS "START 0" to 1909 or use Vi app → DND
  4. BSNL: SMS "START DND" to 1909
  5. All carriers: SMS START 0 to 1909 for universal DND
